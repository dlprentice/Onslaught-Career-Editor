## What this is

A preservation project for *Battle Engine Aquila* (2003). This public repository holds:

- a **frozen copy of the Godot rebuild** (`rebuild/`), retained as reference and not built or tested here; the rebuild
  is developed in https://github.com/dlprentice/onslaught-godot. It aims to be 1:1 with retail from startup to exit,
  with level 100 playable to completion. `OnslaughtRebuild.Parity` is the simulation owner and
  `OnslaughtRebuild.Host` the presentation owner; the earlier `OnslaughtRebuild.Core`, `Client` and `Godot` projects
  are reference material, not a second production simulation;
- the **companion** (`companion/`), Onslaught Companion: the Godot .NET app for careers, saves, backups, settings,
  music and lore for the original game and Onslaught CE, including CE launcher settings and the steps for updating CE (the companion contacts nothing). The old AppCore patching
  core is gone; the file-safety and save-layout code the companion uses lives in the companion, and Git keeps the rest;
- a frozen copy of the game documentation (`reverse-engineering/`), whose home is
  https://github.com/dlprentice/onslaught-preservation, where new findings go, and our own tools.

Elsewhere: the byte-matching decompilation, the reverse-engineering authority, is public as
[onslaught-decomp](https://github.com/dlprentice/onslaught-decomp), and the native source port as
[Onslaught CE](https://github.com/dlprentice/onslaught-ce). The Ghidra checkpoint, the RE campaign
machinery, scrubbed decompiler passages and the full pre-flatten history are in the private
`dlprentice/onslaught-re-archive`. The native port's public source and downloads are Onslaught CE, public at
https://github.com/dlprentice/onslaught-ce, generated by the decompilation's export tool; nothing is committed there by hand.
The decompilation's public export is https://github.com/dlprentice/onslaught-decomp, and the game documentation is
published at https://github.com/dlprentice/onslaught-preservation. [`GOAL.md`](GOAL.md) states the outcomes, [`PROGRAM.md`](PROGRAM.md) the work
queue, [`CURRENT_CAPABILITIES.md`](CURRENT_CAPABILITIES.md) what is demonstrated, and
[onslaught-godot's parity record](https://github.com/dlprentice/onslaught-godot/blob/main/rebuild/PARITY.md) the rebuild's
current milestones and measured parity. The local [`rebuild/PARITY.md`](rebuild/PARITY.md) is frozen.

## Checkouts and branches

- `main` is the integration branch; a lane merges into it when its own gate passes. Lane branches start from the
  flattened `main`; never merge a pre-flatten branch or resurrect its plans.
- The maintainer's working checkout may sit on slow external storage, and it holds the canonical `local-lab/`. Give
  such a checkout light I/O only: do builds, test runs, captures and worktrees in a clone on a fast internal disk and
  point it at the canonical lab ([LOCAL_LAB_OVERLAY.md](LOCAL_LAB_OVERLAY.md)). Worktrees never receive a copied
  corpus. Where the checkout and the clone are on a given machine is in the ignored `local-data/` notes.
- Current rebuild development is documented in [onslaught-godot](https://github.com/dlprentice/onslaught-godot); the
  local `rebuild/README.md` records the frozen copy. The companion's own
  [README](companion/OnslaughtToolkit.Godot/README.md) describes its workflows and validation limits. Which clone and
  reference folders this machine uses is in the ignored `local-data/rebuild-env.sh` and the private notes, never in a
  tracked file.

## Ground rules

- Game/save writes require an informed user choice and a verified recovery copy before overwriting original data, and
  never happen while the game runs. The companion's `GameInstaller` (`companion/OnslaughtToolkit.Godot/Files/GameWrites.cs`:
  a verified backup set outside the game folder, a running check before the backup and again before the swap, an
  exchange swap undone if the displaced file is not the backed-up one, a read-back) is the model. Never manufacture an
  "original" from an already modified file, and never destroy career data as a side effect.
- The pristine specimen `local-lab/safe-copy-bea-pristine/BEA.exe.original.backup` (SHA-256 `74154bfa…`) is the
  byte-measurement baseline: read it, never write it. The lab folder's `BEA.exe` (`e1436ef7…`) is patched. Every
  byte or address finding names the specimen it was read from, with its hash; measure the exact selected file
  before making a new claim about any other copy.
- Do not synthesize `.bes` saves. Start from a real baseline and preserve length, reserved fields and unknown bytes.
  `tests_shared/fixtures/gold_career_save.bin` is the one tracked save.
- Never track retail binaries or assets, converted retail material, arbitrary saves, raw debugger logs, bulky
  captures, Ghidra databases or backups, decompiler output, decomp source, credentials or `.env*`.
  `npm run test:safety` enforces the boundary; a small registered set of the app's own screenshots is the one
  allowance (`reverse-engineering/project-meta/attribution.md`, `tools/check_registered_screenshots.py`). It also
  fails live text (docs, code and comments alike) that quotes original-game bytes (a run of hex byte tokens, or a long
  hex string that is not a SHA-1 or SHA-256) or a private machine path. The frozen copies (`reverse-engineering/`
  and `rebuild/`) are not read by those rules; every reviewed exception is listed with its reason in
  `tools/public_allowlist_safety_check.py`, and an exception whose text is gone fails as stale.
- Every behaviour claim cites a capture, byte comparison, focused test, or pinned source file and line. Decompiler
  output, a plausible name or a model's opinion proves nothing; the decompilation is the naming authority, cited by
  function, never quoted. Static evidence establishes identities and structures; only controlled runtime evidence
  establishes causality and values. Write unknowns as open questions with the cheapest falsifier.
- Ghidra is retired as an authority. The working project `local-lab/ghidra-projects/BEA/BEA.gpr` and the cold copies
  kept outside this checkout (the ignored local notes say where) stay untouched (restore a copy, never open one in place; opening without
  `-readOnly` can roll its `db.NNNNN` version). Nothing Ghidra-derived returns to this repository.
- `local-lab/` and `local-data/` are real ignored directories inside this checkout. Never run `git clean` here
  (`-x`/`-X` would erase the lab) and never stage them; add paths explicitly. Before calling anything in them stale,
  grep the tooling and tests, not only the docs: a 2026-08-06 cleanup deleted inputs whose identities were pinned in
  tooling. Retention belongs to `local-lab/INDEX.md` and the machine's deletion queue.
- Licensing: the rebuild is GPL and may adapt the pinned GPL source in `references/Onslaught` and the decompilation's
  simulation (recorded per unit in `rebuild/PROVENANCE.md`); it consumes locally materialized retail data but never
  contains retail executables, decompiler output or separately licensed material. All project code (companion, rebuild,
  tools) is GPL-3.0-only and documentation and lore are CC BY-SA 4.0, as `REUSE.toml` maps them; ExuberantParrot's PR #1
  passages also keep their MIT notice. Contributions come in under the same terms (`CONTRIBUTING.md`). None of it
  merges with private retail material into one licensing boundary.
- The rebuild's simulation (`OnslaughtRebuild.Parity`) is deterministic given its inputs: the tape, the retail data
  and options files it reads as the game does, and the virtual clock. It never reads wall time, locale, environment or
  thread scheduling, and it has no presentation, process, network or GPU dependency (the earlier `Core`'s stricter
  contract is [DETERMINISM.md](rebuild/DETERMINISM.md)). Tests compare it with recorded references Present by
  Present; missing references, empty selections and new skips are not passes.
- No telemetry: nothing in this repository collects or sends usage data. A network feature names exactly what it
  contacts and why, and reads only public data.
- C# only, built in code: no `.gd` files, no editor-authored scenes or resources (a `.tscn` only as a one-node entry
  wrapper), shader source in C# strings, one production owner per subsystem. Repository tooling stays Python.
- Reviews by other agents or models are optional input to reproduce, not authority
  ([REVIEW-PROTOCOL.md](reverse-engineering/REVIEW-PROTOCOL.md)); hosted reviewers never receive retail material
  or secrets. Hosted CI and release automation are outside this phase; release claims need the selected platform's
  validation; Linux evidence alone does not establish Windows behaviour.

## Definition of done

1. The smallest gate that could falsify the change passed: docs → `git diff --check` and `npm run test:docs`; added
   files → `npm run test:safety`; tool changes → the affected `_tests.py` cases; rebuild code → the affected Parity
   tests, then the Parity suite and Host build as the [live rebuild guide](https://github.com/dlprentice/onslaught-godot/blob/main/rebuild/README.md) describes; companion → its `npm test`.
2. A new or edited tracked `.md` has `Status:`, `Last updated:` (or `Date:`) and `Summary:` (or `Verdict:`) in its
   header and no volatile counts. `tools/doc_header_backlog.txt` may only shrink.
3. Stage only the scoped paths, commit plainly and push the working branch. Commits here are public: keep the Co-Authored-By line, add no Claude-Session line, and describe the change itself, not which agent or role made it.

## Gotchas

- `BEA.exe` writes `setuphistory.txt` and `cardid.txt` into its working directory: launch a copy from its own
  folder. Linux Steam's install is `~/.local/share/Steam/steamapps/common/Battle Engine Aquila/`.
- `tools/check_installed_game_claims.py` bans standing promises about the installed game (for example that it is
  never modified); describe the backup rule instead.
- `.worktrees/` and `.claude/worktrees/` are ignored because a broad `git add -A` has twice swept unrelated work into
  a commit.
