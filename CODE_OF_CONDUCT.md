# Code of Conduct

Status: active
Last updated: 2026-11-11 (new; the project inbox added)
Summary: this project follows the Contributor Covenant, version 2.1, and reports of unacceptable behaviour go privately to the maintainer through the private report form or the project inbox.

This project follows the Contributor Covenant, version 2.1:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>. It applies in this repository's issues, pull
requests and discussions, and wherever a person represents the project.

To report unacceptable behaviour, write privately to the maintainer through this repository's private report form:
open the Security tab and choose "Report a vulnerability"
(<https://github.com/dlprentice/Onslaught-Career-Editor/security/advisories/new>). Please do not report it in a public
issue or pull request. If you would rather use email, write to the project inbox,
<onslaughtce@gmail.com>.
