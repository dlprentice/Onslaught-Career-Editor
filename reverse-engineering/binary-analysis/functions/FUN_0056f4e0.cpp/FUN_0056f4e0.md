array-construction helper over 12-byte elements. The private later source,

these fields as `type = PT_STRIP`, `numIndices = 0` and `indices = NULL`.
The body, element stride and caller role jointly support the constructor
identity; the zero/one stores alone would not identify an object type.

The old `FUN_0056f4e0` filename remains for link stability. The
[reviewed manifest](../../../../tools/cohort-specs/library-nvtristrip-20260926.manifest.tsv)
changes the name/comment/tags while preserving the body and existing prototype.
There is no direct call to this body; execution is through the callback.

The earlier note's unknown object type is resolved within this structural
scope. It does not establish all strip-generation behavior, failure handling
